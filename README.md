# US Traffic Accident Analysis Using Hadoop

## Project Overview

This project focuses on analyzing the US Traffic Accident dataset using the Hadoop ecosystem. The main objective is to process large-scale traffic accident data and extract meaningful insights using distributed data processing techniques.

The project uses:

- Hadoop HDFS for distributed storage
- MapReduce for batch data processing
- Apache Pig for high-level data analysis

---

## Dataset

The original dataset used in this project is the **US Accidents Dataset** collected by Sobhan Moosavi.

Dataset Source:

https://www.kaggle.com/datasets/sobhanmoosavi/us-accidents

The dataset contains countrywide traffic accident records from the United States, including information such as:

- Accident severity
- Location (City, State, Latitude, Longitude)
- Time and date information
- Weather conditions
- Temperature
- Visibility
- Distance
- Other contextual attributes

The complete dataset is not uploaded to this repository because of GitHub file size limitations. A small sample dataset is provided inside the `dataset` folder for demonstration purposes.
